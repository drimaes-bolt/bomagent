# 03. 부서별 활용

> 다봄의 데이터는 하나이고 화면과 권한은 부서별로 다르다. 연구소는 설계 중에 사내 품목과 조달 위험을 보고, 구매/자재는 해독 대신 선택과 승인을 하고, 생산관리는 구조와 효력 시점을 정하고, 회계는 원가 숫자의 근거와 변경 영향을 본다.

질의 ID는 부서 머리글자를 쓴다. D-1~D-4, P-1~P-4, M-1~M-3, Q-1~Q-3은 R02 2장의 질의 케이스를 그대로 이어받았고, 나머지는 이번에 더했다. 회계(F)는 새로 만들었다.

## 0. 한눈에 보기

| 부서 | 지금 불편한 점 | 다봄에서 하는 일 | 얻는 것 | 승인 권한 |
|---|---|---|---|---|
| 연구소 | 사내 표준·재고·단종 정보를 모른 채 부품을 고르고, 조달 위험을 구매 회신 뒤에 안다(R02 2.0) | E-BOM 업로드, 사양 확인 응답, 후보 부품 등록, 설계 변경 업로드 | 설계 중에 사내 품목과 위험을 안다. 같은 질문을 다시 받지 않는다 | 사양 확정, FFF 판정, L1 설계 변경 |
| 구매/자재 | 표기 해독과 견적 취합이 수작업이고 대체품 판단이 개인 경험에 기댄다(R02 2.0, R01 2.2) | 매칭표 검토와 제조사 선택, 흡수·통합 승인, 신규 품목 등록 요청, 통보 대응 | 해독 시간이 줄고 판단 근거가 남는다 | 제조사 선택, L2·L3 변경, 신규 품목 등록 요청, 신규 발번 승인(기준정보 담당과 함께) |
| 생산관리(생산기술 포함) | 구버전 시트로 자재를 불출하고 착수 가능 여부를 전화로 확인한다(R02 2.0) | 구조 확정, 제품·반제품 품번 입력, 공정 구분·LOSS, 효력 시점 결정 | 최신 M-BOM과 변경 효력 시점이 분명해진다 | 구조 확정, 제품·반제품 품번, L4 변경, 효력 시점 |
| 회계 | 원가 롤업과 where-used를 엑셀로 다시 계산하고(R02 1.3.4), 설계 변경으로 생긴 불용 재고를 라인에서 뒤늦게 안다(R10 6단계) | 자재비 롤업 조회, 변경 원가 영향 검토, 불용 위험 재고 확인 | 원가 숫자의 출처와 시점이 남는다 | 원가 기준 단가 확정, 기준을 넘는 원가 영향 승인 [제안] |
| 품질(참여) | 인증 구성 변경과 특채 만료를 사람이 챙긴다 | 인증 구성 변경 경고 확인, L2 품질 확인, 특채·편차 승인 | 인증 구성과 품질 기준이 지켜진다 | L2 품질 확인, 특채·편차 |
| 영업·고객 대응(참여) | 고객 지정 부품과 승인 상태가 BOM과 떨어져 있다 | 고객 지정 부품 등록, 고객 승인 상태와 적용 시장 입력 | 지정 부품 위반을 막는다 | 고객 승인 기록 |

품질·영업은 요청 범위(연구소·생산관리·구매/자재·회계) 밖이지만 승인 경로에 들어 있어 참여 부서로 넣었다(OI-04).

## 4. 회계

| ID | 상황 | 질의 예 | 다봄 출력 | 기능 |
|---|---|---|---|---|
| F-1 | 모델별 자재비 | "E51K 1대 자재비와 기준 단가는?" | 제품 → 반제품 → 부품 롤업. 단가 기준(재고 단가·최근 매입가·표준 단가 중 하나), 기준일, 환율 표시. 고객 지정 부품은 따로 표시(R04 2.2) | `CST-01` |
| F-2 | 개정별 자재비 추이 | "S0부터 지금까지 자재비가 어떻게 바뀌었나" | 개정별 자재비와 변경 사유 | `CST-02` |
| F-3 | 변경 원가 영향 | "이 변경 패키지로 대당 원가와 남는 재고는?" | 변경 전후 대당 자재비, 연간 영향(생산 계획 기준), 처분 비용(폐기·재작업), 적용 시점 | `CST-03` |
| F-4 | 불용 위험 재고 | "설계 변경이나 단종으로 쓸 곳이 사라지는 재고는?" | where-used가 0이 되는 품목과 재고 금액, 다른 모델 사용 가능 여부 | `CST-04` |
| F-5 | 단가 인상 영향 | "칩저항이 20% 오르면 연간 얼마인가" | 영향 품목·모델·연간 금액 | `CST-05` |
| F-6 | 원가 근거 확인 | "이 숫자는 어디서 왔나" | 단가 출처·시점·승인자, 계산식 | `CST-01` `MDM-06` |

- 원가 계산은 모두 규칙 계층이 한다. 어떤 환율·단가 기준으로 계산했는지 표시되지 않은 원가는 승인 대상으로 올리지 않는다(R02 시나리오 G).
- 반제품 품번은 재공(WIP) 회계 단위다(R02 1.3.4). 구조를 확정할 때 회계 의견을 받는다. [제안]
- 3-Way Matching·결제 조건·자금 계획은 현 범위 밖이다. 원가 기준 단가와 함께 회계가 정한다(OI-13).

## 6. 영업·고객 대응 (참여)

- 고객 지정 부품 목록을 등록하고 갱신한다(`MDM-07`). 지정 부품은 이후 대체 추천에서 빠진다(RB-DP-02).
- 제품의 적용 시장(`Target_Market`: 산업용·전장 등)을 지정한다. 승인 경로가 시장에 따라 달라진다([docs/07 5장](07_변경관리_추적.md)).
- 전장 제품의 고객 승인 상태(`Customer_Approval_Status`)를 기록한다.
