# 09. 검증과 평가

> 다봄은 두 가지를 따로 잰다. 하나는 판단의 품질(필드 정확도, 오답과 기권)이고, 다른 하나는 시스템의 안전(막아야 할 것을 규칙 검증기가 막는가)이다. 골든셋과 레드팀은 학습에 쓰지 않는다. 수치 목표는 0단계 베이스라인 실측 뒤에 정한다.

---

## 1. 평가 원칙

1. 필드 단위로 채점한다. MPN·분류·값·패키지·유전체·공차를 따로 본다(R03 2.3).
2. 오답과 기권을 따로 센다. 기권을 오답으로 세면 모델이 모르는 것도 답하게 된다(R03 2.3).
3. 평가셋은 학습에서 뺀다. 파일 단위로 학습 금지 라벨을 붙이고 수집 단계에서 해시로 걸러 낸다(R03 위험 R13).
4. 결정론 검증기를 먼저 둔다. 모델이 틀려도 검증기가 위험을 막으면 시스템은 안전하다. "모델은 틀릴 수 있고, 시스템은 틀린 것을 통과시키지 않는다"(R02 6장).
5. [가상] 데이터로 잰 수치는 실적으로 쓰지 않는다.

## 4. 자동 검증기

이전 작업(KK7~KK16 다단계 M-BOM 전개, 2026-10-11)에서 실제로 돌린 검사를 다봄의 결정론 검증기로 옮긴다.

| 검사 | 통과 기준 |
|---|---|
| 원본 보존 | 원본 E-BOM 시트와 값 차이 0 |
| 개정 이력 완결 | 모든 개정 시트가 개정 이력에 있다 |
| 수량 보존 | E-BOM 유래 행의 수량 합 = 원본. 차이는 삭제·분리 근거가 있을 때만 |
| 통합 전후 수량 | 같은 자품번 통합 전후의 부품 행 정미수량 합이 같다 |
| 양식 일치 | Amaranth 22열 머리글이 ERP 추출본과 같다 |
| 코드 형식 | 정규식 통과(제품·반제품은 제외) |
| 코드 유일성 | 전 제품 범위에서 한 코드에 MPN 하나, 한 MPN에 코드 하나 |
| 기존 코드 오용 | 기존 ERP 코드를 다른 MPN에 쓰지 않는다 |
| 같은 모품번 안 중복 | 같은 자품번 중복은 실장·미사용 쌍만 허용 |
| 발번 보류 | 보류 행은 등록 파일에 들어가지 않는다 |
| 기준선 조건 | 동결 시 미결 MPN 0, 시제 품목 0 |
| 모델 입력 | 호출 기록에 단가·재고·거래처 조건 필드가 없다 |

[관측] 위 검사로 KK13~KK16 네 파일을 확인한 결과 고유 ERP 코드 448개에서 한 코드 다중 MPN 0건, 한 MPN 다중 코드 0건, E51K 코드의 다른 MPN 사용 0건이었다. 데이터가 [가상]이므로 검증기 동작 확인으로만 쓴다.

## 6. 단계별 수용 기준 [가안]

| 단계 전환 | 기준 |
|---|---|
| 1단계 → 2단계 | KPI-11이 G1 파일의 대부분(가안: 16개 중 15개 이상)에서 정답, KPI-12·13 100%, KPI-18 위반 0, KPI-20 0(1단계 기능에 걸리는 레드팀 항목 기준), 4개 부서 키유저 시험 사용, KPI-01 실측 |
| 2단계 → 3단계 | KPI-14·15가 골든셋 합의 기준 충족, 실제 양산 모델 1개를 다봄 기준으로 기준선 등록, 변경 패키지 처리 실적 |
| 3단계 → 4단계 | KPI-19 기준 충족, KPI-04 측정, KPI-07 0건 유지 |

수치는 골든셋 채점 규칙 합의(R03 2.3)와 베이스라인 실측 뒤 확정한다.

## 7. 베이스라인 실측 (0단계)

R03 D-N의 세 가지에 부서별 측정을 더했다. 스톱워치 수준이어도 숫자가 있는 편이 없는 것보다 낫다(R03 D-N).

| 측정 | 방법 | 담당 |
|---|---|---|
| ① E-BOM 1건을 M-BOM으로 바꾸는 시간 | 담당자 3명 × 3건 | 구매/자재 |
| ② MPN 매핑 오류율 | 과거 오발주 건수 ÷ 총 발주 라인 | 구매/자재 |
| ③ 대체품 탐색 소요 일수 | 최근 5건 | 구매/자재·연구소 |
| ④ 변경 반영 리드타임 | 최근 변경 5건의 요청부터 ERP 반영까지 | 생산관리 |
| ⑤ 모델 1개 자재비 산출 시간 | 1회 측정 | 회계 |
| ⑥ E-BOM 1건 처리 중 연구소에 다시 묻는 건수 | 최근 3건 | 연구소·구매/자재 |

## 8. 운영 중 모니터링

- 채택률·교정률(KPI-22), 규칙 차단 건수(R02 6장의 가드레일 차단율), 미결 잔존 건수, 처리 시간을 주 단위로 본다.
- 모델 버전별로 같은 골든셋 결과를 비교한다.
- 모델을 바꿀 때는 골든셋과 레드팀을 다시 돌리고, 통과해야 교체한다(NFR-07).
