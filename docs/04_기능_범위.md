# 04. 기능 범위와 우선순위

> 다봄은 9개 모듈로 나뉜다. 1단계(초안)는 E-BOM을 받아 사내 기준정보로 M-BOM 초안과 ERP 등록 파일을 만드는 데까지다. 승인·기준선·변경 추적은 2단계, 외부 통보 알림과 원가 영향은 3단계에 붙인다. 단계 정의와 종료 조건은 [docs/10](10_로드맵_추진체계.md)에 있다.

---

## 3. 1단계(초안) 범위

| 모듈 | 1단계에 넣는 기능 |
|---|---|
| `IMP` | IMP-01~07 |
| `MAT` | MAT-01·02·03·04(조회)·05·07 |
| `BLD` | BLD-01~06 |
| `COD` | COD-01~04 |
| `CFM` | CFM-01·04(파일 생성)·05 |
| `MDM` | MDM-01·02·03·05·06·07 |

1단계의 완성 기준은 "E-BOM 한 건을 올리면 사내 기준정보로 맞춘 Amaranth 양식 M-BOM 초안, 확인 요청 목록, ERP 코드 발번 내역이 나온다"이다. 외부 후보 검색(MAT-06)은 NC AI 모델의 후보 판정 태스크가 준비되는 시점에 맞춰 2단계에 넣는다.

## 4. 비기능 요구

| ID | 항목 | 요구 |
|---|---|---|
| NFR-01 | 보안 | 사내망 배치, 역할별 권한, 단가·금액 마스킹, 모델 입력에서 단가·재고·거래처 조건 제외, 외부 전송 기록 |
