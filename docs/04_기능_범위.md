# 04. 기능 범위와 우선순위

> 다봄은 9개 모듈과 2026-11-23에 제안한 2개 모듈(`PRD` 생산 준비, `QLT` 품질 확인)로 나뉜다. 1단계(초안)는 E-BOM을 받아 사내 기준정보로 M-BOM 초안과 ERP 등록 파일을 만드는 데까지다. 승인·기준선·변경 추적은 2단계, 외부 통보 알림과 원가 영향은 3단계에 붙인다. 단계 정의와 종료 조건은 [docs/10](10_로드맵_추진체계.md)에 있다.

|---|---|---|---|---|

`PRD`·`QLT`는 2026-11-23에 더했다(DEC-16, [docs/14](14_부서기능_확장검토.md)).

### 1.1 BOM 뿌리 지도 [제안 · DEC-18]

모듈이 늘어도 시작과 뿌리는 BOM이다([docs/01 1.6](01_프로젝트_정의.md)). 모듈마다 BOM의 무엇을 읽고 무엇을 돌려주는지 적었다. 줄기는 처음 만든 기능(E-BOM → M-BOM 변환과 추적), 가지는 그 위에 부서별로 뻗은 기능이다.

| 모듈 | 층 | BOM에서 읽는 것 | BOM에 돌려주는 것 | 쓰는 부서 |
|---|---|---|---|---|
| 가져오기 `IMP` | 줄기 | 연구소가 올린 E-BOM 파일과 원문 행 | 원문 보존, 정규화 병기, 확인 요청 | 연구소 |
| 맞추기 `MAT` | 줄기 | E-BOM 행의 사양·MPN | 행별 맞춤 결과(기존 품목·재고·사용 이력·후보·거래처·AVL 공급 제품)와 근거 | 구매/자재·연구소 |
| 만들기 `BLD` | 줄기 | 맞춘 행과 보드 구성 | M-BOM 구조(제품 → 반제품 → 부품), 정미수량·LOSS·필요수량 | 생산관리 |
| 품번 `COD` | 줄기 | M-BOM 자품번 후보와 사양 | ERP 코드 재사용·발번·보류 | 기준정보 담당·구매/자재 |
| 확정 `CFM` | 줄기 | M-BOM 초안과 확인 요청 | 확정 개정, 기준선, ERP 등록 파일 | 전 부서 |
| 추적 `TRK` | 줄기 | M-BOM 개정, E-BOM 개정 | 변경 패키지, 개정 이력, 효력·처분, 변경 통지 | 전 부서 |
| 알림 `ALR` | 가지 | BOM의 MPN·제조사와 where-used | 영향 모델·개정·재고, 변경 패키지 초안 | 구매/자재·연구소 |
| 원가 `CST` | 가지 | M-BOM 행의 수량과 단가 | 모델별 자재비, 개정별 추이, 변경 원가 영향 | 회계·구매/자재 |
| 생산 준비 `PRD` | 가지 | 확정 M-BOM의 참조부호·수량·LOSS·실장 구분 | 좌표 대조 결과, 피더 목록 초안, LOSS 기준, 불출 목록 | 생산기술·자재 |
| 품질 확인 `QLT` | 가지 | M-BOM 개정 사이에 바뀐 행, 신규 품목·거래처 | 수입검사·초도품 확인 목록, 선언서 보유 현황 | 품질 |
| 기준정보 `MDM` | 받침 | BOM 행이 맞춰 보는 품목·거래처·후보 풀·카탈로그·AVL 공급 제품, BOM 이력(어느 모델에 썼나) | 후보 풀, 사용 이력 품목, 카탈로그, AVL·공급 제품 DB, 사전·룰북, 권한 | 기준정보 담당·관리자 |

- 새 모듈·기능을 더할 때는 이 표에 한 줄을 먼저 더하거나 기존 줄을 고친다. "BOM에서 읽는 것"을 적을 수 없으면 BOM에 뿌리가 없는 일이다. 기능 행을 만들지 않고 `docs/11`에 미결(`OI-nn`)로 올려 범위를 정한다(CLAUDE.md 5장).
- 예외 하나: `MAT-12`(분류별 품목 탐색)는 E-BOM 없이 연다. 읽는 것이 BOM 행이 아니라 BOM이 맞춰 볼 사내 품목이고, 설계자가 E-BOM을 쓰기 전에 보는 입구다. 이 입구에서 고른 부품이 E-BOM 행이 되고 다시 맞추기로 돌아온다.
- `MDM`은 가지가 아니라 줄기를 받치는 데이터다. 가지 기능이 새로 기준정보를 요구하면 `MDM`에 적재 기능을 더한다(예: `MDM-08`·`MDM-09`).

## 3. 1단계(초안) 범위

| 모듈 | 1단계에 넣는 기능 |
|---|---|
| `IMP` | IMP-01~07 |
| `MAT` | MAT-01·02·03·04(조회)·05·07·10·12 |
| `BLD` | BLD-01~06 |
| `COD` | COD-01~04 |
| `CFM` | CFM-01·04(파일 생성)·05 |
| `MDM` | MDM-01·02·03·05·06·07·08(양식·예시)·09·10(시연용 적재) |
| `PRD` | PRD-03(LOSS 기준표를 BLD-04 입력으로) |

1단계의 완성 기준은 "E-BOM 한 건을 올리면 사내 기준정보로 맞춘 Amaranth 양식 M-BOM 초안, 확인 요청 목록, ERP 코드 발번 내역이 나온다"이다. 외부 후보 검색(MAT-06)은 NC AI 모델의 후보 판정 태스크가 준비되는 시점에 맞춰 2단계에 넣는다.
