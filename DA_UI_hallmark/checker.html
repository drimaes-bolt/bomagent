검사기가 보지 못하는 것

  • 한 장(한 절)에 주장이 하나인지, 문구가 구체적인지, 숫자가 맞는지. 사람이 읽고 판단한다.
  • 다른 서버(CDN)에서 불러온 CSS의 규칙. 화면에 그려진 결과는 본다.
  • 움직임 줄이기 설정을 켠 화면, 실제 화면 캡처의 색 면적. 색 면적은 요소 크기로 대략 계산한다.
  • 보조기기(화면 읽기 프로그램)로 쓸 수 있는지. 접근성 전체 확인은 사람이 보조기기로 직접 써 봐야 한다.
